# Problem Text
Data la parabola di equazione $y = -x^2 + 2x + 3$, determina vertice, asse di simmetria, fuoco e direttrice.

# Solution
I coefficienti sono $a = -1$, $b = 2$, $c = 3$. L'ascissa del vertice è $x_V = -\frac{b}{2a} = -\frac{2}{-2} = 1$. Sostituendo nell'equazione, $y_V = -1 + 2 + 3 = 4$, quindi il vertice è $V(1,4)$ e l'asse di simmetria è $x = 1$. Per una parabola $y = ax^2 + bx + c$, il fuoco ha coordinate $\left(x_V, y_V + \frac{1}{4a}\right)$ e la direttrice è $y = y_V - \frac{1}{4a}$. Poiché $a = -1$, si ha $\frac{1}{4a} = -\frac{1}{4}$. Allora il fuoco è $F\left(1, 4 - \frac{1}{4}\right) = F\left(1, \frac{15}{4}\right)$ e la direttrice è $y = 4 + \frac{1}{4} = \frac{17}{4}$.
