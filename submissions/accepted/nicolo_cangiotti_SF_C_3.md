# Problem Text
Risolvi le seguenti due equazioni:
1) $$4^{x+1} = 4^{2x-3}$$
2) $$\log(3x-2) = \log(x+4)$$

# Solution
**Equazione 1 (Esponenziale)**
$$4^{x+1} = 4^{2x-3}$$
Avendo basi uguali, grazie all'iniettività dell'esponenziale uguagliamo gli esponenti:
$$x + 1 = 2x - 3$$
Portiamo i numeri a sinistra e le $$x$$ a destra:
$$1 + 3 = 2x - x$$
$$4 = x$$
La soluzione è **$$x = 4$$**.

**Equazione 2 (Logaritmica)**
$$\log(3x-2) = \log(x+4)$$
Prima di procedere, poniamo le **Condizioni di Esistenza (C.E.)** per la positività degli argomenti:
1. $$3x - 2 > 0 \implies 3x > 2 \implies x > \frac{2}{3}$$
2. $$x + 4 > 0 \implies x > -4$$

L'intersezione tra le due condizioni è la condizione più stringente, ovvero $$x > \frac{2}{3}$$.

Ora eguagliamo gli argomenti:
$$3x - 2 = x + 4$$
$$3x - x = 4 + 2$$
$$2x = 6$$
$$x = 3$$

Controlliamo se $$3$$ rispetta le C.E.: essendo $$3 > \frac{2}{3}$$, la soluzione è accettabile.
La soluzione è **$$x = 3$$**.
