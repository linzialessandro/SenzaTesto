# Problem Text
Risolvi (mostrando tutti i passaggi) la seguente equazione di secondo grado:
$$x^2 + 7x + 12 = 0$$

# Solution
Questa è un'equazione di secondo grado completa ($$ax^2 + bx + c = 0$$), i cui coefficienti sono:
$$a = 1$$
$$b = 7$$
$$c = 12$$

Calcoliamo il valore del discriminante ($$\Delta$$):
$$\Delta = b^2 - 4ac = 7^2 - 4(1)(12) = 49 - 48 = 1$$

Avendo $$\Delta > 0$$, ci aspettiamo due soluzioni reali e distinte. Applichiamo la formula generale:
$$x_{1,2} = \frac{-b \pm \sqrt{\Delta}}{2a}$$
$$x_{1,2} = \frac{-7 \pm \sqrt{1}}{2(1)} = \frac{-7 \pm 1}{2}$$

Troviamo le due soluzioni separando il segno positivo da quello negativo:
$$x_1 = \frac{-7 - 1}{2} = \frac{-8}{2} = -4$$
$$x_2 = \frac{-7 + 1}{2} = \frac{-6}{2} = -3$$

Le soluzioni cercate sono pertanto **$$x = -4$$** e **$$x = -3$$**.
