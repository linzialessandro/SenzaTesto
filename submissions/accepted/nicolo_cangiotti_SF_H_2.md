# Problem Text
Sia data la seguente funzione:
$$y = f(x) = \frac{x+1}{x-1}$$

Segui il percorso guidato per studiare la funzione, indicando l'operazione corretta da svolgere e calcolandone il risultato.

**1. Il campo di esistenza (dominio)** della funzione $$f(x)$$ si calcola ponendo:
- [ ] $$x-1 > 0$$
- [ ] $$x-1 \neq 0$$
- [ ] $$x-1 < 0$$
*Calcola il campo di esistenza.*

**2. Le intersezioni con l'asse $$x$$** si calcolano ponendo:
- [ ] $$f(x) = 0$$
- [ ] $$f(x) = 1$$
- [ ] $$f(x) = x$$
*In questo caso, l'intersezione con l'asse $$x$$ è:*
- [ ] $$x = 0$$ e $$x = -1$$
- [ ] $$x = 1$$
- [ ] $$x = -1$$

**3. Le intersezioni con l'asse $$y$$** si calcolano ponendo:
- [ ] $$y = f(y)$$
- [ ] $$y = f(1)$$
- [ ] $$y = f(0)$$
*In questo caso, l'intersezione con l'asse $$y$$ è:*
- [ ] $$y = -1$$
- [ ] $$y = -1$$ e $$y = 1$$
- [ ] $$y = 0$$

**4. La positività** si determina ponendo:
- [ ] $$f(x) = 0$$
- [ ] $$f(x) < 0$$
- [ ] $$f(x) > 0$$

Mostra i calcoli che hai fatto per rispondere alle domande.

# Solution
**1. Campo di Esistenza**
Il campo di esistenza di una funzione razionale fratta si determina imponendo che il denominatore sia diverso da zero, per evitare la divisione per zero.
- **Risposta corretta:** $$x-1 \neq 0$$
- **Calcolo:** $$x \neq 1 \implies D = \mathbb{R} \setminus \{1\}$$.

**2. Intersezioni con l'asse $$x$$**
L'asse $$x$$ ha equazione $$y=0$$, quindi per trovare le intersezioni si pone l'espressione della funzione uguale a zero.
- **Risposta corretta (impostazione):** $$f(x) = 0$$
- **Risposta corretta (risultato):** $$x = -1$$
- **Calcolo:** $$\frac{x+1}{x-1} = 0 \implies x+1 = 0 \implies x = -1$$.

**3. Intersezioni con l'asse $$y$$**
L'asse $$y$$ ha equazione $$x=0$$, quindi si deve sostituire $$0$$ al posto di $$x$$ nella funzione.
- **Risposta corretta (impostazione):** $$y = f(0)$$
- **Risposta corretta (risultato):** $$y = -1$$
- **Calcolo:** $$y = f(0) = \frac{0+1}{0-1} = \frac{1}{-1} = -1$$.

**4. Positività**
La positività (cioè dove il grafico sta sopra l'asse delle ascisse) si trova imponendo che i valori assunti dalla funzione siano strettamente maggiori di zero.
- **Risposta corretta:** $$f(x) > 0$$
- **Calcolo:** $$\frac{x+1}{x-1} > 0$$. Il numeratore è positivo per $$x > -1$$, il denominatore per $$x > 1$$. Studiando i segni si ottiene che $$f(x) > 0$$ per $$x \in (-\infty, -1) \cup (1, +\infty)$$.
