# Problem Text
Esegui, se possibile, le seguenti divisioni tra monomi. Se una divisione non è possibile nel dominio dei monomi, spiegane il motivo.
a) $$6a^3b^3c^2 : \left(-3a^2b^2c\right)$$
b) $$4xy^3 : 2x^3y$$

# Solution
**Divisione a)**
La divisione tra i due monomi è definita e possibile.
Eseguiamo l'operazione tra i coefficienti numerici e applichiamo le proprietà delle potenze sulle singole lettere:
- $$6 : (-3) = -2$$
- $$a^{3-2} = a^1$$
- $$b^{3-2} = b^1$$
- $$c^{2-1} = c^1$$

Dunque:
$$
6a^3b^3c^2 : \left(-3a^2b^2c\right) = -2abc
$$

**Divisione b)**
La divisione, se si vuole mantenere il risultato sotto forma di monomio, è impossibile. Osservando la lettera $$x$$, l'esponente nel dividendo (che è $$1$$) è strettamente minore rispetto all'esponente nel divisore (che è $$3$$).
