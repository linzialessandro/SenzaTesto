# Problem Text
Risolvi l'equazione biquadratica $x^4 - 5x^2 + 4 = 0$.

# Solution
Poniamo $t = x^2$, con $t \ge 0$. L'equazione diventa $t^2 - 5t + 4 = 0$. Scomponiamo: $(t-1)(t-4) = 0$, quindi $t=1$ o $t=4$. Tornando alla variabile $x$: se $x^2 = 1$, allora $x = \pm 1$; se $x^2 = 4$, allora $x = \pm 2$. L'insieme delle soluzioni è $S = \{-2, -1, 1, 2\}$.
