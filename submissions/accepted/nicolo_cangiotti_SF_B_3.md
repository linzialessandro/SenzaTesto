# Problem Text
Risolvi le seguenti due equazioni:
1) $$2^{x+3} = 2^{3x-1}$$
2) $$\log(2x+3) = \log(4x-1)$$

# Solution
**Equazione 1 (Esponenziale)**
$$2^{x+3} = 2^{3x-1}$$
Le due potenze hanno la stessa base (2). Poiché la funzione esponenziale è iniettiva, possiamo eguagliare direttamente gli esponenti:
$$x + 3 = 3x - 1$$
Riordiniamo i termini portando le $$x$$ a destra (o sinistra):
$$3 + 1 = 3x - x$$
$$4 = 2x$$
$$x = 2$$
La soluzione è **$$x = 2$$**.

**Equazione 2 (Logaritmica)**
$$\log(2x+3) = \log(4x-1)$$
Per le equazioni logaritmiche, la prima cosa da fare è imporre le **Condizioni di Esistenza (C.E.)** affinché gli argomenti siano positivi:
1. $$2x + 3 > 0 \implies 2x > -3 \implies x > -\frac{3}{2}$$
2. $$4x - 1 > 0 \implies 4x > 1 \implies x > \frac{1}{4}$$

L'intersezione di queste due condizioni è l'intervallo più restrittivo: $$x > \frac{1}{4}$$. Questa è la C.E. generale dell'equazione.

Avendo lo stesso logaritmo ad ambo i membri, possiamo eguagliare gli argomenti:
$$2x + 3 = 4x - 1$$
$$3 + 1 = 4x - 2x$$
$$4 = 2x$$
$$x = 2$$

Verifichiamo la soluzione rispetto alle C.E.: $$2 > \frac{1}{4}$$ è vero. La soluzione è quindi accettabile.
La soluzione è **$$x = 2$$**.
