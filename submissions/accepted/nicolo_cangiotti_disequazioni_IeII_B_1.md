# Problem Text
Indica se le seguenti affermazioni sono vere o false:
1. $$-2$$ è un numero intero maggiore di $$-5$$.
2. $$x^2$$ è minore o uguale a zero per tutti i possibili valori di $$x$$.
3. La disequazione $$x-3>0$$ è *impossibile*.
4. $$x^2+1>0$$ è una disequazione di primo grado.

# Solution
1. **Vero.** Sulla retta orientata dei numeri reali, il numero $$-2$$ si trova alla destra di $$-5$$, perciò $$-2 > -5$$.
2. **Falso.** Il quadrato di un qualsiasi numero reale è sempre maggiore o uguale a zero ($$x^2 \ge 0$$). Non è mai negativo, al massimo è uguale a zero (se $$x=0$$).
3. **Falso.** La disequazione $$x-3>0$$ non è impossibile. Si può risolvere portando il $$-3$$ a destra, ottenendo infinite soluzioni: $$x > 3$$.
4. **Falso.** Il polinomio $$x^2+1$$ contiene il termine $$x^2$$, di secondo grado. Di conseguenza, si tratta di una disequazione di secondo grado, non di primo.
