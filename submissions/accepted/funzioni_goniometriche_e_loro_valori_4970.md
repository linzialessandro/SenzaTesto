# Problem Text
L'angolo $\theta$ appartenente al terzo quadrante soddisfa $\csc \theta = -2$. Determina i valori esatti di $\sin \theta$, $\cos \theta$, $\tan \theta$ e $\cot \theta$.

# Solution
Poiché $\csc \theta = \frac{1}{\sin \theta} = -2$, si ha $\sin \theta = -\frac{1}{2}$. Essendo $\theta$ nel terzo quadrante, $\cos \theta < 0$. Usando l'identità fondamentale $\sin^2 \theta + \cos^2 \theta = 1$, otteniamo $\cos^2 \theta = 1 - \left(-\frac{1}{2}\right)^2 = 1 - \frac{1}{4} = \frac{3}{4}$, quindi $\cos \theta = -\frac{\sqrt{3}}{2}$ (segno negativo per il terzo quadrante). Allora $\tan \theta = \frac{\sin \theta}{\cos \theta} = \frac{-1/2}{-\sqrt{3}/2} = \frac{1}{\sqrt{3}} = \frac{\sqrt{3}}{3}$, e $\cot \theta = \frac{1}{\tan \theta} = \sqrt{3}$. In conclusione: $\sin \theta = -\frac{1}{2}$, $\cos \theta = -\frac{\sqrt{3}}{2}$, $\tan \theta = \frac{\sqrt{3}}{3}$, $\cot \theta = \sqrt{3}$.
