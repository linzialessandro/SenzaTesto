# Problem Text
Osserva le due curve rappresentate nel piano cartesiano e seleziona per ciascuna la risposta corretta.

**(a)** Una curva a forma di $$S$$ verticale distesa (tipo $$y=x^3$$) che si estende indefinitamente lungo l'asse $$x$$ e l'asse $$y$$.
- [ ] La curva è una funzione iniettiva, ma non suriettiva.
- [ ] La curva non è una funzione.
- [ ] La curva è una funzione biettiva.

**(b)** Un'ellisse centrata nell'origine degli assi.
- [ ] La curva è una funzione suriettiva.
- [ ] La curva non è una funzione.
- [ ] La curva è una funzione biettiva.

# Solution
**(a)** Risposta corretta: **La curva è una funzione biettiva.**
La cubica mostrata in figura supera il test della linea verticale (ad ogni $$x$$ corrisponde un'unica $$y$$) quindi è una funzione. Supera anche il test della linea orizzontale, garantendo l'iniettività. Poiché si estende verso $$-\infty$$ in basso e $$+\infty$$ in alto, copre tutto l'asse $$y$$, garantendo la suriettività. Quindi è biettiva.

**(b)** Risposta corretta: **La curva non è una funzione.**
Tracciando una qualsiasi retta verticale passante internamente all'ellisse (ad esempio l'asse $$y$$ stesso), si interseca la figura in due punti (uno positivo e uno negativo). Ciò viola la definizione di funzione, in cui a un elemento $$x$$ non può mai essere associato più di un elemento $$y$$.
