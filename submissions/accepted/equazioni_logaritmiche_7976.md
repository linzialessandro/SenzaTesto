# Problem Text
Risolvi l'equazione logaritmica $\log_2(x-1) = 3$ nel campo reale.

# Solution
Per definizione di logaritmo, $\log_a b = c$ significa $a^c = b$. Quindi abbiamo $x-1 = 2^3 = 8$. Da cui $x = 9$. Verifichiamo le condizioni di esistenza: $x-1 > 0$ cioè $x>1$, e $9>1$ quindi accettabile. Soluzione: $x=9$.
