# Problem Text
Sia data la seguente retta in forma implicita:
$$r: 2x + 3y - 2 = 0$$

Fornire la formula **esplicita** di $$r$$.

# Solution
Per passare dalla forma implicita ($$ax + by + c = 0$$) alla forma esplicita ($$y = mx + q$$), dobbiamo isolare la variabile $$y$$ a primo membro.

Partiamo dall'equazione data:
$$2x + 3y - 2 = 0$$

Portiamo i termini con la $$x$$ e il termine noto a secondo membro (cambiando segno):
$$3y = -2x + 2$$

Dividiamo tutti i termini per il coefficiente della $$y$$, ovvero $$3$$:
$$y = \frac{-2x + 2}{3}$$
$$y = -\frac{2}{3}x + \frac{2}{3}$$

La formula esplicita della retta $$r$$ è quindi **$$y = -\frac{2}{3}x + \frac{2}{3}$$**.
