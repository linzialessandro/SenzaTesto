# Problem Text
Dire se le seguenti affermazioni sono vere (V) o false (F), giustificando la risposta:
1. Nell'espressione $$\displaystyle \frac{3}{2x-6}$$ il denominatore si annulla per $$x=3$$.
2. Un'equazione di secondo grado ha almeno una soluzione.
3. Per trovare il campo di esistenza di un'equazione fratta si pone il denominatore diverso da zero.
4. Si può dividere per zero qualsiasi numero.

# Solution
1. **Vero (V)**: Il denominatore è $$2x-6$$. Se sostituiamo $$x=3$$, otteniamo $$2(3)-6 = 6-6 = 0$$.
2. **Falso (F)**: Un'equazione di secondo grado può non avere alcuna soluzione nell'insieme dei numeri reali (questo accade quando il discriminante $$\Delta$$ è strettamente minore di zero).
3. **Vero (V)**: Il Campo di Esistenza (C.E.) di una frazione algebrica si determina proprio imponendo che il denominatore sia diverso da zero, condizione necessaria affinché la divisione abbia significato.
4. **Falso (F)**: La divisione per zero è un'operazione priva di significato in matematica; non è possibile dividere alcun numero per zero.
