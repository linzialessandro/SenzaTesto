# Problem Text
Il numero complesso $z = -1 + i\sqrt{3}$ è espresso in forma algebrica. Determina la sua forma trigonometrica e la sua forma esponenziale.

# Solution
Calcoliamo il modulo: $|z| = \sqrt{(-1)^2 + (\sqrt{3})^2} = \sqrt{1+3} = 2$. L'argomento $\theta$ soddisfa $\cos\theta = \frac{-1}{2}$ e $\sin\theta = \frac{\sqrt{3}}{2}$, quindi $\theta = \frac{2\pi}{3}$. La forma trigonometrica è $z = 2\left(\cos\frac{2\pi}{3} + i\sin\frac{2\pi}{3}\right)$, mentre quella esponenziale è $z = 2e^{i\frac{2\pi}{3}}$.
