# Problem Text
Risolvi (mostrando tutti i passaggi) la seguente equazione di secondo grado:
$$4x^2 + 4x + 1 = 0$$

# Solution
L'equazione è già scritta in forma canonica ($$ax^2 + bx + c = 0$$), con coefficienti:
$$a = 4$$
$$b = 4$$
$$c = 1$$

Procediamo al calcolo del discriminante ($$\Delta$$):
$$\Delta = b^2 - 4ac = 4^2 - 4(4)(1) = 16 - 16 = 0$$

Poiché **$$\Delta = 0$$**, l'equazione ammette **una sola soluzione reale** (o due soluzioni reali e coincidenti). Possiamo trovarla usando la formula risolutiva standard:
$$x = \frac{-b \pm \sqrt{\Delta}}{2a}$$
$$x = \frac{-4 \pm 0}{2(4)}$$
$$x = \frac{-4}{8} = -\frac{1}{2}$$

*(Nota: si poteva anche notare fin dall'inizio che il trinomio $$4x^2+4x+1$$ è lo sviluppo del quadrato di un binomio, per cui l'equazione poteva essere riscritta come $$(2x+1)^2 = 0$$, portando direttamente alla soluzione $$2x+1 = 0 \implies x = -1/2$$).*

La soluzione dell'equazione è dunque **$$x = -\frac{1}{2}$$**.
