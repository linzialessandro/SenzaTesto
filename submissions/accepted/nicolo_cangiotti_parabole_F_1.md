# Problem Text
Risolvi (mostrando tutti i passaggi) la seguente equazione di secondo grado:
$$9x^2 + 6x + 1 = 0$$

# Solution
L'equazione è in forma canonica ($$ax^2 + bx + c = 0$$), e i suoi coefficienti sono:
$$a = 9$$
$$b = 6$$
$$c = 1$$

Calcoliamo il discriminante ($$\Delta$$):
$$\Delta = b^2 - 4ac = 6^2 - 4(9)(1) = 36 - 36 = 0$$

Dato che **$$\Delta = 0$$**, l'equazione ha **una soluzione reale** (due coincidenti). La troviamo con la formula risolutiva:
$$x = \frac{-b \pm \sqrt{\Delta}}{2a}$$
$$x = \frac{-6 \pm 0}{2(9)}$$
$$x = \frac{-6}{18} = -\frac{1}{3}$$

*(Osservazione: il polinomio $$9x^2 + 6x + 1$$ è lo sviluppo del quadrato di binomio $$(3x+1)^2$$, quindi bastava imporre $$(3x+1)^2 = 0 \implies 3x+1 = 0 \implies x = -1/3$$).*

La soluzione dell'equazione è pertanto **$$x = -\frac{1}{3}$$**.
