# Problem Text
Risolvi le seguenti due equazioni:
1) $$3^{2x+1} = 3^{x-1}$$
2) $$\log(2x+1) = \log(3x-4)$$

# Solution
**Equazione 1 (Esponenziale)**
$$3^{2x+1} = 3^{x-1}$$
Le due funzioni esponenziali hanno la medesima base (3). Possiamo uguagliare gli esponenti in virtù dell'iniettività della funzione esponenziale:
$$2x + 1 = x - 1$$
Riportiamo i termini incogniti da una parte e i noti dall'altra:
$$2x - x = -1 - 1$$
$$x = -2$$
La soluzione è **$$x = -2$$**.

**Equazione 2 (Logaritmica)**
$$\log(2x+1) = \log(3x-4)$$
Imponiamo preliminarmente le **Condizioni di Esistenza (C.E.)** per la positività degli argomenti del logaritmo:
1. $$2x + 1 > 0 \implies x > -\frac{1}{2}$$
2. $$3x - 4 > 0 \implies x > \frac{4}{3}$$

La condizione comune è l'intersezione delle due, ovvero la più restrittiva: $$x > \frac{4}{3}$$.
Ora possiamo eguagliare direttamente gli argomenti:
$$2x + 1 = 3x - 4$$
$$1 + 4 = 3x - 2x$$
$$5 = x$$

Verifichiamo la validità della soluzione: poiché $$5 > \frac{4}{3}$$, la soluzione cade ampiamente all'interno del dominio di esistenza.
La soluzione è **$$x = 5$$**.
