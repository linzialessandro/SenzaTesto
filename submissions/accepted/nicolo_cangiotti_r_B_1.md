# Problem Text
Sia data la seguente retta in forma implicita:
$$r: 4x + 3y - 1 = 0$$

Fornire la formula **esplicita** di $$r$$.

# Solution
Per ricavare la forma esplicita ($$y = mx + q$$) partendo dalla forma implicita ($$ax + by + c = 0$$), è sufficiente esplicitare la variabile $$y$$.

L'equazione iniziale è:
$$4x + 3y - 1 = 0$$

Manteniamo il termine in $$y$$ a sinistra e spostiamo gli altri termini a destra (ricordando di cambiare il segno):
$$3y = -4x + 1$$

Infine, dividiamo tutti i termini per il coefficiente della $$y$$ ($$3$$):
$$y = \frac{-4x + 1}{3}$$
$$y = -\frac{4}{3}x + \frac{1}{3}$$

L'equazione esplicita della retta $$r$$ è perciò **$$y = -\frac{4}{3}x + \frac{1}{3}$$**.
