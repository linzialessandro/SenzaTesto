# Problem Text
Risolvi (mostrando tutti i passaggi) la seguente equazione di secondo grado:
$$x^2 - 6x + 5 = 0$$

# Solution
L'equazione è già scritta in forma normale ($$ax^2 + bx + c = 0$$), con:
$$a = 1$$
$$b = -6$$
$$c = 5$$

Calcoliamo prima di tutto il discriminante ($$\Delta$$):
$$\Delta = b^2 - 4ac = (-6)^2 - 4(1)(5) = 36 - 20 = 16$$

Essendo $$\Delta > 0$$, l'equazione ammette due soluzioni reali e distinte. Applichiamo la formula risolutiva:
$$x_{1,2} = \frac{-b \pm \sqrt{\Delta}}{2a}$$
$$x_{1,2} = \frac{-(-6) \pm \sqrt{16}}{2(1)} = \frac{6 \pm 4}{2}$$

Calcoliamo le due soluzioni separando i segni:
$$x_1 = \frac{6 - 4}{2} = \frac{2}{2} = 1$$
$$x_2 = \frac{6 + 4}{2} = \frac{10}{2} = 5$$

Le soluzioni dell'equazione sono quindi **$$x = 1$$** e **$$x = 5$$**.
