# Problem Text
Esegui, se possibile, le seguenti divisioni tra monomi. Se una divisione non è possibile nel dominio dei monomi, spiegane il motivo.
a) $$-15a^3b^3c^2 : \left(-3a^2b^2c\right)$$
b) $$12xy^4 : 4x^4y$$

# Solution
**Divisione a)**
Questa divisione è possibile poiché per ogni lettera l'esponente nel dividendo è maggiore o uguale all'esponente nel divisore.
- Per il coefficiente numerico: $$(-15) : (-3) = 5$$
- Per la parte letterale: $$a^{3-2} = a$$, $$b^{3-2} = b$$, $$c^{2-1} = c$$

Mettendo assieme, il risultato è:
$$
-15a^3b^3c^2 : \left(-3a^2b^2c\right) = 5abc
$$

**Divisione b)**
La divisione non è possibile (non produce come risultato un monomio). Concentriamoci sulla lettera $$x$$:
- Esponente di $$x$$ nel dividendo: $$1$$
- Esponente di $$x$$ nel divisore: $$4$$

Essendo $$1 < 4$$, la divisione originerebbe una lettera con esponente negativo, violando la definizione rigorosa di monomio intero.
