# Problem Text
Esegui, se possibile, le seguenti divisioni tra monomi. Se una divisione non è possibile nel dominio dei monomi, spiegane il motivo.
a) $$-27a^3b^3c^2 : \left(-3a^2b^2c\right)$$
b) $$15xy^3 : 3x^3y$$

# Solution
**Divisione a)**
La divisione è possibile perché il dividendo contiene tutte le lettere del divisore, con esponenti maggiori o uguali:
- Coefficiente: $$(-27) : (-3) = +9$$
- Parte letterale: $$a^{3-2} = a^1$$, $$b^{3-2} = b^1$$, $$c^{2-1} = c^1$$

Unendo i risultati otteniamo:
$$
-27a^3b^3c^2 : \left(-3a^2b^2c\right) = 9abc
$$

**Divisione b)**
La divisione non è possibile (come monomio). Osserviamo gli esponenti della lettera $$x$$:
- Nel dividendo l'esponente di $$x$$ è $$1$$
- Nel divisore l'esponente di $$x$$ è $$3$$

Poiché $$1 < 3$$, la divisione genererebbe un termine $$x^{-2}$$ che non rientra nella definizione di monomio.
