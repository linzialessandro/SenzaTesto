# Problem Text
Indica se le seguenti affermazioni sono vere o false:
1. $$-7$$ è un numero intero maggiore di $$2$$.
2. $$(-2)^2=-4$$.
3. La disequazione $$x^2<0$$ è *impossibile*.
4. $$2x+x+1>0$$ è una disequazione di primo grado.

# Solution
1. **Falso.** Il numero $$-7$$ è negativo, mentre $$2$$ è positivo. Un numero negativo è sempre strettamente minore di uno positivo, quindi $$-7 < 2$$.
2. **Falso.** Elevare al quadrato un numero negativo fornisce un risultato positivo, poiché il prodotto di due segni meno dà più: $$(-2) \cdot (-2) = +4$$.
3. **Vero.** Una potenza pari (come il quadrato) restituisce sempre un numero maggiore o uguale a zero nei reali. È dunque impossibile che un quadrato sia strettamente minore di zero.
4. **Vero.** L'espressione $$2x+x+1$$ contiene solo l'incognita $$x$$ elevata a potenza $$1$$. Semplificando si ottiene $$3x+1>0$$, che è chiaramente una disequazione di primo grado.
