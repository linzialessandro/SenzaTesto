# Problem Text
Sia data la seguente retta in forma implicita:
$$r: 5x + 4y - 1 = 0$$

Fornire la formula **esplicita** di $$r$$.

# Solution
L'obiettivo è trasformare l'equazione dalla sua forma implicita ($$ax + by + c = 0$$) alla forma esplicita ($$y = mx + q$$), esplicitando quindi l'incognita $$y$$.

Partendo da:
$$5x + 4y - 1 = 0$$

Manteniamo il termine con la $$y$$ a primo membro e spostiamo gli altri termini al secondo, cambiandoli di segno:
$$4y = -5x + 1$$

A questo punto dividiamo tutto per il coefficiente di $$y$$, che è $$4$$:
$$y = \frac{-5x + 1}{4}$$
$$y = -\frac{5}{4}x + \frac{1}{4}$$

La formula esplicita della retta $$r$$ è **$$y = -\frac{5}{4}x + \frac{1}{4}$$**.
