# Problem Text
Esegui, se possibile, le seguenti divisioni tra monomi. Se una divisione non è possibile nel dominio dei monomi, spiegane il motivo.
a) $$-10a^3b^3c^2 : \left(-2a^2b^2c\right)$$
b) $$6x^3y : 2x^3y^3$$

# Solution
**Divisione a)**
Poiché per ciascuna variabile l'esponente nel dividendo è maggiore o uguale a quello del divisore, la divisione si può eseguire.
- Il coefficiente è: $$(-10) : (-2) = 5$$
- La parte letterale è: $$a^{3-2}b^{3-2}c^{2-1} = abc$$

Il risultato della prima divisione è perciò $$5abc$$.

**Divisione b)**
L'operazione in questo caso non darà come risultato un monomio. Guardando la lettera $$y$$, notiamo che l'esponente nel primo monomio ($$1$$) è minore rispetto all'esponente nel secondo ($$3$$). Eseguendo l'operazione avremmo una potenza ad esponente negativo ($$y^{-2}$$), che non è ammessa nella definizione di monomio.
