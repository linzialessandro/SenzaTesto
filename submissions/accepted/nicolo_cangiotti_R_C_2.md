# Problem Text
Sia data la seguente retta in forma esplicita:
$$y = 3x + 7$$

Indica chi è il **coefficiente angolare** ($$m$$) e chi è l'**intercetta** ($$q$$). Spiega il significato geometrico di coefficiente angolare e intercetta.

# Solution
Osservando l'equazione della retta in forma esplicita, $$y = mx + q$$:
- Il coefficiente angolare $$m$$ è il valore numerico che moltiplica la variabile $$x$$. Quindi, **$$m = 3$$**.
- L'intercetta $$q$$ (o ordinata all'origine) è il termine noto indipendente. Quindi, **$$q = 7$$**.

**Significato geometrico**
- **Coefficiente angolare ($$m$$)**: Dal punto di vista grafico, identifica l'inclinazione (la **pendenza**) della retta. Esprime la variazione che l'ordinata $$y$$ subisce all'aumentare di una singola unità dell'ascissa $$x$$. Avendo $$m = 3$$ (un numero positivo), la retta sarà crescente, cioè "salirà" verso destra.
- **Intercetta ($$q$$)**: Rappresenta il punto esatto di **intersezione tra la retta e l'asse verticale ($$y$$)**. Poiché $$q = 7$$, possiamo localizzare il punto di intersezione alle coordinate $$(0; 7)$$.
