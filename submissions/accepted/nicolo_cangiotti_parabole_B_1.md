# Problem Text
Risolvi (mostrando tutti i passaggi) la seguente equazione di secondo grado:
$$x^2 + 4x + 3 = 0$$

# Solution
Questa equazione si presenta in forma normale ($$ax^2 + bx + c = 0$$), con coefficienti:
$$a = 1$$
$$b = 4$$
$$c = 3$$

Iniziamo calcolando il discriminante ($$\Delta$$):
$$\Delta = b^2 - 4ac = 4^2 - 4(1)(3) = 16 - 12 = 4$$

Poiché $$\Delta > 0$$, l'equazione possiede due soluzioni reali distinte. Le ricaviamo usando la formula risolutiva:
$$x_{1,2} = \frac{-b \pm \sqrt{\Delta}}{2a}$$
$$x_{1,2} = \frac{-4 \pm \sqrt{4}}{2(1)} = \frac{-4 \pm 2}{2}$$

Separiamo i due segni per trovare le singole soluzioni:
$$x_1 = \frac{-4 - 2}{2} = \frac{-6}{2} = -3$$
$$x_2 = \frac{-4 + 2}{2} = \frac{-2}{2} = -1$$

Le soluzioni dell'equazione sono dunque **$$x = -3$$** e **$$x = -1$$**.
