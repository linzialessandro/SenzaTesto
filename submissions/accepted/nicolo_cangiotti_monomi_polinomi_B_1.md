# Problem Text
Dire se le seguenti affermazioni sono vere (V) o false (F), correggendo quelle false:
1. $$(x-y)(y+x)=x^2-y^2$$
2. $$x-(-x)=x^2$$
3. $$x\cdot (-x)=-2x$$
4. $$x\cdot(x+1)=(1+x)\cdot x$$

# Solution
1. **Vero (V)**: Il prodotto notevole somma per differenza $$(x-y)(x+y)$$ (che per la proprietà commutativa è uguale a $$(x-y)(y+x)$$) dà come risultato $$x^2 - y^2$$.
2. **Falso (F)**: Cambiando il segno a causa del meno davanti alla parentesi si ottiene la somma $$x + x = 2x$$, che è diverso da $$x^2$$.
3. **Falso (F)**: Essendo una moltiplicazione, si moltiplicano prima i segni e poi si sommano gli esponenti, da cui $$x \cdot (-x) = -x^2$$. Non si tratta di una somma che produrrebbe $$-2x$$.
4. **Vero (V)**: Risulta vera in base alla proprietà commutativa del prodotto. Entrambi i lati, se espansi, danno $$x^2 + x$$.
