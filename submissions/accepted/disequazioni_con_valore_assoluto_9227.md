# Problem Text
Risolvi la disequazione $|3x - 4| \leq 8$.

# Solution
La disequazione è del tipo $|A| \leq k$ con $k > 0$, quindi è equivalente a $-8 \leq 3x - 4 \leq 8$. Sommando $4$ a tutti i membri otteniamo $-4 \leq 3x \leq 12$. Dividendo per $3$ (positivo, quindi il verso non cambia) si ha $-\frac{4}{3} \leq x \leq 4$. L'insieme delle soluzioni è quindi l'intervallo $[-\frac{4}{3}, 4]$.
