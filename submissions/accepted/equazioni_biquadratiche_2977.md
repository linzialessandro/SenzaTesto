# Problem Text
Risolvi l'equazione $x^4 - 5x^2 + 4 = 0$.

# Solution
Poniamo $t = x^2$. L'equazione diventa $t^2 - 5t + 4 = 0$. Scomponiamo: $(t - 1)(t - 4) = 0$, quindi $t = 1$ oppure $t = 4$. Poiché $t = x^2$, abbiamo $x^2 = 1 \Rightarrow x = \pm 1$ e $x^2 = 4 \Rightarrow x = \pm 2$. Le soluzioni sono $x = \pm 1, \pm 2$.
