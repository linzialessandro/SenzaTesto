# Problem Text
Risolvi l'equazione $|2x - 3| = 7$.

# Solution
Per la definizione di valore assoluto, l'equazione $|A| = k$ (con $k \ge 0$) equivale a $A = k$ oppure $A = -k$. Quindi, da $|2x - 3| = 7$ otteniamo due equazioni:
$$2x - 3 = 7 \quad \text{oppure} \quad 2x - 3 = -7.$$
Risolviamo la prima: $2x - 3 = 7 \Rightarrow 2x = 10 \Rightarrow x = 5$.
Risolviamo la seconda: $2x - 3 = -7 \Rightarrow 2x = -4 \Rightarrow x = -2$.
Verifichiamo le soluzioni nell'equazione originale:
Per $x = 5$, $|2 \cdot 5 - 3| = |10 - 3| = 7$, ok.
Per $x = -2$, $|2 \cdot (-2) - 3| = |-4 - 3| = |-7| = 7$, ok.
Pertanto l'insieme delle soluzioni è $S = \{-2, 5\}$.
