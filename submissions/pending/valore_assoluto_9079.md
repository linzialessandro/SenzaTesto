# Problem Text
Risolvi la seguente equazione: $$|2x - 3| = 5$$

# Solution
Per la definizione di valore assoluto, dobbiamo considerare due casi:

1. \(2x - 3 \ge 0\) (cioè \(x \ge \frac{3}{2}\)): in questo caso \(|2x - 3| = 2x - 3\), quindi l'equazione diventa \(2x - 3 = 5\), da cui \(2x = 8\) e \(x = 4\). Poiché \(4 \ge \frac{3}{2}\), la soluzione è accettabile.

2. \(2x - 3 < 0\) (cioè \(x < \frac{3}{2}\)): in questo caso \(|2x - 3| = -(2x - 3) = -2x + 3\), quindi l'equazione diventa \(-2x + 3 = 5\), da cui \(-2x = 2\) e \(x = -1\). Poiché \(-1 < \frac{3}{2}\), la soluzione è accettabile.

Pertanto, l'insieme delle soluzioni è: $$\{ -1, 4 \}$$
