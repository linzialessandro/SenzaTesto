# Problem Text
Calcola $(1-i)^4$ utilizzando la formula di De Moivre.

# Solution
Scriviamo $z=1-i$ in forma trigonometrica. Il modulo è $|z|=\sqrt{1^2+(-1)^2}=\sqrt{2}$. L'argomento è $\theta=-\frac{\pi}{4}$ poiché il punto è nel quarto quadrante. Quindi $z=\sqrt{2}(\cos(-\frac{\pi}{4})+i\sin(-\frac{\pi}{4}))$. Per la formula di De Moivre: $z^4=(\sqrt{2})^4(\cos(4\cdot(-\frac{\pi}{4}))+i\sin(4\cdot(-\frac{\pi}{4})))=4(\cos(-\pi)+i\sin(-\pi))=4(-1+0i)=-4$. Quindi $(1-i)^4=-4$.
