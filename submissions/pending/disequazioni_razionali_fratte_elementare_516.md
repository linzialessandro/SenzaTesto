# Problem Text
Risolvi la disequazione fratta $\dfrac{x-1}{x+2}>0$.

# Solution
Condizione di esistenza: $x\neq -2$. Zeri: $x=1$ (numeratore). Studio del segno: il quoziente è positivo per $x<-2$ o $x>1$. Poiché la disequazione è stretta, $x=1$ è escluso. Soluzione: $x\in(-\infty,-2)\cup(1,+\infty)$.
