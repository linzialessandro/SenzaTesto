# Problem Text
Risolvi l'equazione biquadratica $x^4 - 4x^2 + 3 = 0$.

# Solution
Poniamo $t = x^2$. L'equazione diventa $t^2 - 4t + 3 = 0$, che si scompone come $(t-1)(t-3) = 0$, quindi $t=1$ o $t=3$. Troviamo $x$: se $t=1$, $x^2=1$ da cui $x = \pm 1$; se $t=3$, $x^2=3$ da cui $x = \pm \sqrt{3}$. L'insieme delle soluzioni è $\{ -1, 1, -\sqrt{3}, \sqrt{3} \}$.
