# Problem Text
Risolvi l'equazione biquadratica $x^4 - 13x^2 + 36 = 0$.

# Solution
Poniamo $t = x^2$. L'equazione diventa $t^2 - 13t + 36 = 0$. Scomponiamo: $(t-4)(t-9) = 0$, quindi $t = 4$ o $t = 9$. Poiché $t = x^2$, abbiamo $x^2 = 4$ o $x^2 = 9$. Le soluzioni sono quindi $x = \pm 2$ e $x = \pm 3$.
