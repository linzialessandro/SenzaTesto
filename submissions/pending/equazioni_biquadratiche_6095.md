# Problem Text
Risolvi l'equazione biquadratica $x^4 - 5x^2 + 4 = 0$.

# Solution
Poniamo $t = x^2$. L'equazione diventa $t^2 - 5t + 4 = 0$. Risolviamo: 

$$
t^2 - 5t + 4 = 0
$$

Le soluzioni sono $t_1 = 1$ e $t_2 = 4$. Quindi $x^2 = 1$ dà $x = \pm 1$, mentre $x^2 = 4$ dà $x = \pm 2$. In conclusione, le soluzioni sono $x = -2, -1, 1, 2$.
