# Problem Text
Calcola il valore del logaritmo: $\log_{4} 64$.

# Solution
Per definizione, $\log_{a} b = c$ se e solo se $a^c = b$. Qui $a=4$, $b=64$. Osserviamo che $64 = 4^3$, quindi $4^3 = 64$. Di conseguenza, $\log_{4} 64 = 3$.
