# Problem Text
Considera il seguente insieme di dati: $4, 8, 6, 10$. Calcola la media aritmetica, la varianza e lo scarto quadratico medio (popolazione).

# Solution
La media aritmetica è: $\bar{x} = \frac{4+8+6+10}{4} = \frac{28}{4} = 7$. Gli scarti dalla media sono: $-3, 1, -1, 3$. I loro quadrati sono: $9, 1, 1, 9$. La varianza è: $\sigma^2 = \frac{9+1+1+9}{4} = \frac{20}{4} = 5$. Lo scarto quadratico medio è: $\sigma = \sqrt{5}$.
