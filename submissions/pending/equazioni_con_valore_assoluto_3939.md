# Problem Text
Risolvi l'equazione $|2x - 3| = 5$.

# Solution
L'equazione $|2x - 3| = 5$ equivale a due equazioni lineari: $2x - 3 = 5$ oppure $2x - 3 = -5$. Risolvendo la prima: $2x = 8 \Rightarrow x = 4$. Risolvendo la seconda: $2x = -2 \Rightarrow x = -1$. Verifica: per $x=4$, $|2 \cdot 4 - 3| = |8 - 3| = 5$, ok; per $x=-1$, $|2 \cdot (-1) - 3| = |-2 - 3| = |-5| = 5$, ok. Quindi le soluzioni sono $x = 4$ e $x = -1$.
