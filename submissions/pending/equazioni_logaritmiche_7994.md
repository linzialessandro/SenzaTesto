# Problem Text
Risolvi l'equazione logaritmica $\log_2 x + \log_2 (x-2) = 3$, specificando il dominio della variabile.

# Solution
Il dominio è $x>0$ e $x-2>0$, quindi $x>2$. Applicando la proprietà del prodotto dei logaritmi, si ha $\log_2[x(x-2)] = 3$. Per la definizione di logaritmo, $x(x-2) = 2^3 = 8$. Allora $x^2-2x-8=0$, le cui soluzioni sono $x=4$ e $x=-2$. Poiché $x=-2$ non appartiene al dominio $x>2$, l'unica soluzione è $x=4$.
