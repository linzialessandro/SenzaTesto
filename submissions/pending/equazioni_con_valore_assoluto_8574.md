# Problem Text
Risolvere l'equazione $|x-2| = 5$.

# Solution
L'equazione $|x-2| = 5$ equivale a $x-2 = 5$ oppure $x-2 = -5$. Dalla prima si ottiene $x = 7$, dalla seconda $x = -3$. Quindi l'insieme delle soluzioni è $\{-3, 7\}$.
