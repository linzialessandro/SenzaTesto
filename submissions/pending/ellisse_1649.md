# Problem Text
Determina vertici, fuochi ed eccentricità dell'ellisse di equazione $\frac{x^2}{9} + \frac{y^2}{4} = 1$.

# Solution
Dall'equazione $\frac{x^2}{9} + \frac{y^2}{4} = 1$, abbiamo $a^2 = 9$ e $b^2 = 4$, quindi $a = 3$ e $b = 2$. Poiché $a > b$, l'asse maggiore è orizzontale. Allora $c = \sqrt{a^2 - b^2} = \sqrt{5}$. I vertici sono $(\pm 3, 0)$ e $(0, \pm 2)$. I fuochi sono $(\pm \sqrt{5}, 0)$. L'eccentricità è $e = \frac{c}{a} = \frac{\sqrt{5}}{3}$.
