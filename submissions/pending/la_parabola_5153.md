# Problem Text
Data la parabola di equazione $y = x^2 - 4x + 5$, determina vertice, fuoco, direttrice e asse di simmetria.

# Solution
Completiamo il quadrato: $y = (x^2 - 4x + 4) + 1 = (x - 2)^2 + 1$. Quindi il vertice è $V(2, 1)$ e l'asse di simmetria è la retta $x = 2$. Poiché il coefficiente della parabola è $a = 1$, la distanza focale è $p = \frac{1}{4a} = \frac{1}{4}$. Il fuoco è $F(2, 1 + \frac{1}{4}) = (2, \frac{5}{4})$ e la direttrice è $y = 1 - \frac{1}{4} = \frac{3}{4}$.
