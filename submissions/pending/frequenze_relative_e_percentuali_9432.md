# Problem Text
In una classe di 20 studenti, le frequenze assolute dei voti ottenuti in un test di matematica sono: voto 4: 2, voto 5: 4, voto 6: 6, voto 7: 5, voto 8: 3. Calcola le frequenze relative (come numero decimale e come percentuale) per ciascun voto.

# Solution
La frequenza relativa di un dato è il rapporto tra la sua frequenza assoluta e il numero totale di osservazioni, che in questo caso è 20. In formula: $f_r = \frac{f_a}{N}$. Calcoliamo per ogni voto:

- Voto 4: $f_a = 2$, quindi $f_r = \frac{2}{20} = 0{,}1$, in percentuale $10\%$.
- Voto 5: $f_a = 4$, quindi $f_r = \frac{4}{20} = 0{,}2$, in percentuale $20\%$.
- Voto 6: $f_a = 6$, quindi $f_r = \frac{6}{20} = 0{,}3$, in percentuale $30\%$.
- Voto 7: $f_a = 5$, quindi $f_r = \frac{5}{20} = 0{,}25$, in percentuale $25\%$.
- Voto 8: $f_a = 3$, quindi $f_r = \frac{3}{20} = 0{,}15$, in percentuale $15\%$.

Verifichiamo che le percentuali sommino a $100\%$: $10+20+30+25+15=100\%$. Tutto corretto.
